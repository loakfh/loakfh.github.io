# Сайт-визитка Бакира

Одностраничный сайт на шести языках: https://loakfh.github.io/
Сейчас это черновик с заглушками, закрытый от поисковиков (`noindex`).

Стек: Astro собирает из файлов контента шесть статических страниц (`/ru/`, `/en/`,
`/tt/`, `/tr/`, `/ja/`, `/de/`), интерактив — на обычном JavaScript, деплой — GitHub Pages.

## Запуск

```sh
npm install
npm run dev        # http://localhost:4321 — правки видны сразу
npm run build      # сборка в dist/
npm run preview    # посмотреть собранный сайт
```

Нужен Node.js 22 или новее.

## Как поменять контент

Вёрстку трогать не нужно — всё лежит в папке `content/`.

| Файл | Что в нём |
|---|---|
| `content.shared.json` | Общее для всех языков: адрес сайта, `noindex`, Telegram, GitHub, email, цифры в первом экране, пути к фото, ссылки проектов |
| `content.ru.json`, `content.en.json` | Готовые тексты |
| `content.tt.json`, `content.tr.json`, `content.ja.json`, `content.de.json` | Черновые переводы — **требуют вашей вычитки** |

Правила:

- Структура шести языковых файлов одинаковая. Добавили карточку в один — добавьте во все.
- Ссылки проектов — в `content.shared.json` → `projectLinks`, подписи к ним — в языковых
  файлах (`projects.items[].links`), в том же порядке.
- Цифры первого экрана — `stats` в общем файле. Чтобы заменить заглушку: поставьте
  `"value": 12, "placeholder": false` и уберите `[ЗАГЛУШКА]` из подписи во всех языках.
- Email: впишите адрес в `person.email` — блок в контактах и строка в vCard появятся сами.
  Пока поле пустое, email на сайте не показывается.

### Заглушки

Всё выдуманное помечено в текстах маркером `[ЗАГЛУШКА]` и на странице показано
пунктирной плашкой. Найти все места: `npm run placeholders`.

Что заменить (одинаково во всех шести языковых файлах):

| Где | Что вписать |
|---|---|
| `hero.stats[1]`, `hero.stats[2]` + `stats` в общем файле | Две цифры первого экрана (сейчас «00»): сколько сайтов собрано и сколько интервью проведено — или другие факты |
| `about.facts` → «Учёба» | Где учитесь, класс или курс |
| `about.facts` → «Город» | Город |
| `projects.items[0].result` | Результат «Личного бренда с ИИ» в цифрах |
| `projects.items[1].task`, `.result` | Какую задачу решает «Траектория» и на какой она стадии |
| `achievements.items[1].text` | Год и трек СКОЛКОВО Старт |
| `achievements.items[2]`, `[3]` | Две карточки целиком: олимпиада и чемпионат (или удалите их) |
| `beyond.items[0..3].text` | По одной фразе про зал, походы, велосипед, путешествия |
| Фото | Портрет и четыре фото «Помимо работы» — см. ниже |

Не заглушки, но проверьте:

- Ссылка «Открыть MVP» у «Траектории» ведёт на `trajectoria-mvp.vercel.app`.
- Три демо-сайта названы без имён компаний («нейрошкола», «учебный центр»,
  «сувенирная компания») — это демо, а не клиенты.
- Имя на сайте — только «Бакир», без фамилии (в том числе в vCard).
- Блок «Как я работаю с ИИ»: макет сайта в анимации — условный пример.

## Фото

Папка `public/assets/photos/`, внутри — плейсхолдеры и `README.md` с размерами.
Коротко: портрет 960 × 1200 (4:5), четыре фото 800 × 600 (4:3), формат WebP.
Положите файлы и поменяйте пути в `content.shared.json` → `photos`.

Картинки для соцсетей (`public/og/`) собираются из текстов: `npm run og`
(нужен установленный Chrome). Запускайте после смены имени или слогана.

## Языки

- Список языков и буквы на клавишах переключателя — `src/lib/i18n.ts`.
- Новый язык: строка в `LANGS`, файл `content/content.<код>.json`, код в списке
  в `scripts/make-og.mjs`, затем `npm run og`.
- Корень сайта `/` перенаправляет на язык: сохранённый выбор → язык браузера → английский.
  GitHub Pages не умеет делать это на сервере, поэтому редирект выполняет скрипт.

## Шрифты

- Golos Text — весь текст. JetBrains Mono — только цифры и латинские подписи:
  татарских букв в нём нет.
- В Golos Text буквы Ğ и ğ нарисованы без бревиса. Эти две буквы подменяются из шрифта
  Onest (`src/fonts/onest-gbreve.woff2`, 2 КБ). Пересобрать файл:
  ```sh
  python3 -m fontTools.subset node_modules/@fontsource-variable/onest/files/onest-latin-ext-wght-normal.woff2 \
    --unicodes=U+011E,U+011F --flavor=woff2 --layout-features='' --output-file=src/fonts/onest-gbreve.woff2
  ```
- Японский выводится системным шрифтом устройства.
- `npm run check:glyphs` проверяет, что все буквы шести языков есть и нарисованы
  со своими знаками. Запускается и при деплое.

## Проверки

```sh
npm run build && npm run preview
npm run check:site    # Chrome: 6 языков × телефон 360px и десктоп, интерактив, редиректы
npm run lighthouse    # три прогона на страницу, медиана
```

Скриншоты и отчёты складываются в `work/` (вне git).

## Деплой

Любой `git push` в ветку `main` запускает сборку и публикацию
(`.github/workflows/deploy.yml`). Статус — вкладка Actions репозитория
`loakfh/loakfh.github.io`.

Если сайт переедет на другой адрес, поменяйте `site.url` в `content.shared.json`:
от него считаются canonical, hreflang, Open Graph и QR-код на визитке.

## Как снять noindex

Когда заглушки заменены:

1. В `content/content.shared.json` поставьте `"noindex": false`.
2. `git commit -am "Открыть сайт для поиска" && git push`.

После этого метатег `robots` исчезнет со всех шести языковых страниц.
Страница-редирект в корне остаётся с `noindex` — так и должно быть.
