# Фото

Сейчас здесь SVG-плейсхолдеры. Положите свои файлы рядом и поменяйте пути
в `content/content.shared.json` → `photos` (там же `width` и `height`).

| Файл | Где на сайте | Пропорции | Размер | Формат |
|---|---|---|---|---|
| `hero.webp` | портрет в первом экране | 4:5, вертикальное | 960 × 1200 px | WebP, до 150 КБ |
| `beyond-basketball.webp` | «Помимо работы» — баскетбол | 4:3 | 800 × 600 px | WebP, до 80 КБ |
| `beyond-books.webp` | «Помимо работы» — книги | 4:3 | 800 × 600 px | WebP, до 80 КБ |
| `beyond-languages.webp` | «Помимо работы» — языки | 4:3 | 800 × 600 px | WebP, до 80 КБ |
| `beyond-lego.webp` | «Помимо работы» — LEGO | 4:3 | 800 × 600 px | WebP, до 80 КБ |

Портрет: лицо в верхней трети кадра, по бокам запас — на телефоне фото обрезается
по ширине. Конвертация из JPG: `cwebp -q 80 photo.jpg -o hero.webp`.

Картинки для соцсетей (`public/og/og-<язык>.png`) собираются командой `npm run og`
из текстов сайта — фото в них нет.

Фото первого экрана (`hero-cutout.webp`) вырезано по контуру, фон прозрачный, 882 × 1280. Голова выглядывает из рамки, низ фото режется рамкой, поэтому снизу нужен ровный срез по телу, а не по фону.
